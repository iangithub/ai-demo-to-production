# 從 AI Demo 到企業上線：從知識引擎、多語互動到治理合規

《從 AI Demo 到企業上線：從知識引擎、多語互動到治理合規》書籍範例原始碼。

AI Demo 能順利回答問題，只是企業 AI 導入的起點。當系統開始連接內部知識、處理多語文件與語音互動，並準備進入正式環境，真正需要面對的是答案可信度、輸出品質、資料治理、資安與責任歸屬。

本書以企業 AI 產品化為主線，整理從功能實作走向正式上線時最常遇到的設計問題、實務陷阱與解決方向，協助開發團隊將創新、營運與治理納入同一套考量。

## 本書內容

- **企業級 RAG 知識引擎**：從 Azure AI Search 與 Foundry IQ 出發，處理檢索品質、答案可信度與企業知識應用的關鍵問題。
- **多語與語音互動**：探討企業翻譯實務，包括專有名詞、文件格式、語音辨識、品質追蹤與人工覆核。
- **AI 治理與合規**：涵蓋資料治理、隱私保護、資安、透明、公平、可追溯性與責任歸屬，協助團隊面對 AI 系統上線後的治理要求。

本書適合開發者、架構師、技術主管與企業 AI 導入團隊閱讀。範例主要採用 **C#** 與 **Azure**；即使使用其他技術棧，書中針對產品化、營運與治理所提出的問題仍具有參考價值。
